# Siddharth Shah

I build agent teams that run the operational work in founder-led companies, through [Upward Ventures](https://upwardvx.com). My own company and life run on 8 of them.

## The roster

| Agent | Runs | What it does |
| --- | --- | --- |
| Chief of Staff | Daily | Morning brief of commitments, follow-ups and what slipped |
| Personal CFO | Weekly + monthly | Cash, taxes and spending against plan |
| Pipeline | Every 4 hours | Finds and qualifies new work |
| Lawyer | Weekly | Answers legal questions with sources and a confidence level |
| Realtor | Twice daily | Watches listings against set criteria |
| Market Watch | Daily | Market moves against holdings |
| Thesis Tracker | Quarterly | Checks each investment thesis against new evidence |
| Portfolio PM | Weekly | Weekly portfolio review |

Haiku gathers, Sonnet analyzes, and Opus is the only model allowed near anything irreversible. The agents are defined in git, so they can move between hosts. Every agent has an explicit silent exit, so a quiet day sends nothing.
